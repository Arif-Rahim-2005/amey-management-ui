# Amey Trading Company — Management System

A web-based management system for Amey Trading Company's clearing and forwarding operations.

## Frontend

Built with React, Vite, and Tailwind CSS.

### Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The frontend development server will display its local URL in the terminal.

## Backend

The backend is maintained separately in the `amey-management-back` repository.

## Features

* User authentication
* Role-based access and user approval
* Dashboard for managing files
